# 후보 기기 정리 & 집에서 확인할 것

## 후보 기기 (기억 기준 — 집에서 확인 필요)

| 기기 | 출시 OS → 최종(예상) | 램 | 서버 적합도 | 메모 |
|---|---|---|---|---|
| 갤럭시 노트10+ | 9 → **12** | 12GB | ⭐⭐⭐ **1순위 후보** | 램 넉넉. 안드로이드 12라 phantom process killer 해제 필요(adb). 배터리 보호(85%) 지원 |
| 갤럭시 폴드3 | 11 → 15 | 12GB | ⭐⭐⭐ | 램 넉넉, 최신 OS. 개발자 옵션에 "하위 프로세스 제한 끄기" 있음. 스냅드래곤 888 발열 주의, 힌지·화면 상태 확인 |
| 갤럭시 A36 | 15 → 최신 | 6~8GB | ⭐⭐ | 저전력·발열 적음, 업데이트 오래감. 중고가가 남아 있어 팔지 고민 |
| 갤럭시 노트8 | 7.1 → **9** | 6GB | ⭐⭐ 보조용 | phantom killer 없음(오히려 편함). 🔴 배터리 노후·부풀음 먼저 확인. **감시용 보조기**로 적합 |
| 갤럭시 폴드6 | 14 → 최신 | 12GB | ⭐ | 성능 최고지만 중고가가 높음 — 서버보단 판매/주력폰 |
| 아이폰 13 프로맥스 | — | — | ❌ 서버 불가 | iOS는 백그라운드 서버 불가. **클라이언트**(Tailscale·파일앱 WebDAV·Jellyfin 앱)로 활용 |

## 구성 아이디어 — 2대 운용

```
[주 서버] 노트10+ 또는 폴드3   ── dufs · Syncthing · (Jellyfin) · sshd
      ▲  5분마다 포트 확인
[감시기] 노트8 또는 A36        ── 주 서버가 죽으면 텔레그램 알림 (+ 가벼운 봇·DNS 등)
```

참고 자료의 약점(“며칠 뒤 조용히 죽고 아무도 모름”)을 남는 폰 한 대로 해결합니다.

## 🏠 집에 가서 기기마다 확인할 것

1. **모델 번호·안드로이드 버전** — 설정 → 휴대전화 정보 → 소프트웨어 정보
2. **램·저장공간** — 설정 → 디바이스 케어(배터리 및 디바이스 케어)
3. **배터리 상태** — 🔴 뒷면이 들뜨거나 화면이 밀려 있으면 **서버 후보에서 제외**
   (Samsung Members → 진단 → 배터리 상태)
4. **배터리 보호 옵션 유무** — 설정 → 배터리 → 배터리 보호 (85% 제한)
5. **충전기·케이블** 상시 연결 가능한지, 둘 곳(통풍) 있는지
6. (선택) **USB-C 유선랜 어댑터** 있으면 Wi-Fi보다 안정적 — 삼성은 대부분 인식
7. 초기화해도 되는 폰인지 (구글/삼성 계정 잠금 풀려 있는지)
